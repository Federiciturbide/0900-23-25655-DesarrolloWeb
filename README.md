# La casa del rincón guatemalteco

Sistema web local para ventas e inventario.

## Inicio rápido

1. Requiere Windows y Python 3.10 o superior.
2. Ejecuta `iniciar.bat`.
3. Abre http://127.0.0.1:8000 en el navegador.

La guía de uso y arquitectura está en [Guia_proyecto.pdf](Guia_proyecto.pdf). La base de datos local se crea en `data/` al iniciar el sistema y no se incluye en Git.
